💡 Things I Learned the Hard Way

  • Always version control your experiments. Lost a week of work once.
  • Documentation is not optional. Future you will thank present you.
  • Premature optimization is real. Make it work first, then make it fast.
  • Backup everything. Cloud storage is cheap, data loss is expensive.
  • Sleep is not negotiable. Tired brain writes terrible code.
  • Ask for help early. Struggling alone for days is not productive.
