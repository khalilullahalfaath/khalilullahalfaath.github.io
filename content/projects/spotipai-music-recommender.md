Final project for the Sistem Temu Balik Informasi (Information Retrieval) course. Built together with Fawwaz Rif'at Revista.

A Streamlit-based web app that displays a music recommendation UI inspired by Spotify, demonstrating two types of recommendation systems: Collaborative Filtering and Content-Based Filtering.

## Features

- User login and registration
- Toggleable dark and light mode
- Separate tabs for Collaborative and Content-Based recommendations
- Graph neural network for collaborative filtering
